## Effect

You fire six shots, each loaded with a fragment of emotional memory (not a
Core Memory: surface impressions). Each shot deals **standard WR damage**
AND, if it hits, inflicts a specific debilitating emotion on the target
(you choose). Consumes 6 rounds.

| Emotion | Effect |
| :---- | :---- |
| Grief | Target is Stunned for 3 Ticks |
| Rage | Target attacks nearest creature (ally or enemy) on next action |
| Shame | Target drops to Prone voluntarily, cannot attack for 5 Ticks |
| Terror | Target flees (Frightened) for 1 round |
| Despair | Target's next roll suffers −4 dice (Pool Penalty) |
| Longing | Target does not act on next turn (lost in memory) |

## Steps

+3 Ticks / +1 round to the duration of all effects per Step.

## Restrictions

- Each emotion may only be applied once per target.
- Maximum 2 shots may target the same enemy.
- Multi-target rules: TN once, Defense per target, AR per target.

## Special

Targets immune to Fear are immune to Terror and Despair only; other
emotions still apply.
