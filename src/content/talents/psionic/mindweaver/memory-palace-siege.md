## Effect

Target one creature within Near range. You assault their Memory Palace
directly. The target experiences all five of their Core Memories
simultaneously: distorted, corrupted, and screaming.

## Resist

ECHO + Focus vs. your Channeling Sum.

- **Success:** They endure. Take **2 Strain**.
- **Failure:** One of their Core Memories is **temporarily Suppressed**
  (cannot be Sparked) for **24 hours**. The GM or target chooses which.
- **Failure by 5+:** **Two Memories** are Suppressed, and the target's
  **Mental Defense Bonus** (from the Bulwark) drops by **1 for 24
  hours**.

## Steps

+1 additional Memory Suppressed per Step (max **+3 Steps**; cannot
exceed the target's total Memory count).

## Special

This does **NOT burn Memories permanently** (that's Memory Hole's
territory at Rank 5). It overwhelms them. The target's sense of self is
intact but shaken, like a house that survived an earthquake but has
cracked foundations.

Bulwark of Memory (BS R3) protects a single Core Memory from this
attack.
